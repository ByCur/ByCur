## 🚀 Selected Projects

### 🤖 AI Knowledge & Workflow Assistant

[![CI](https://github.com/ByCur/ai-knowledge-workflow-assistant/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/ByCur/ai-knowledge-workflow-assistant/actions/workflows/ci.yml)

**React · TypeScript · FastAPI · Python · PostgreSQL · pgvector · Gemini · Ollama · Docker**

Full-stack AI application combining **Retrieval-Augmented Generation (RAG), semantic search and agentic workflows**.

Users can upload PDF/TXT documents, query their knowledge base and use an AI agent capable of executing multi-step actions such as searching documents and creating or managing tasks.

**Highlights**
- Source-grounded RAG with hybrid retrieval and reranking
- PostgreSQL + pgvector semantic search
- Gemini generation and embeddings in the cloud
- Ollama + local embeddings for local development
- Tool-based AI workflow agent with backend guardrails
- Automated tests with pytest
- GitHub Actions CI
- Dockerized development
- Public deployment with Render and Neon

🔗 **[Repository](https://github.com/ByCur/ai-knowledge-workflow-assistant)**  
🌐 **[Live Demo](https://ai-knowledge-frontend.onrender.com)**  
📖 **[API Documentation](https://ai-knowledge-workflow-assistant.onrender.com/docs)**

> The demo backend runs on Render's free tier and may need a short warm-up after inactivity.
